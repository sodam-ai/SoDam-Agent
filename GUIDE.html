0. 먼저 — 이게 뭐예요? (1분)

  • Claude Code: AI에게 일을 시키는 프로그램이에요. 보통 AI 한 명과 대화합니다.
  • SoDam-Agent: 그 Claude Code에 AI 직원 여러 명(팀) 을 한 번에 붙여 주고, 설치한 뒤에도 새 직원을 직접 만들고 가르칠 수 있게 해 주는 도구예요. 예) 기획자 · 화면 개발자 · 서버 개발자 · 검토자 를 한꺼번에 채용하고, 필요하면 새 직원을 더 뽑아 교육하는 느낌.
  • 우리가 할 일: 명령 몇 줄을 Claude Code에 입력하는 것. 그게 전부예요.

💡 용어 한 줄 풀이

  • 플러그인: 프로그램에 끼워 쓰는 부품. (SoDam-Agent가 바로 이 부품이에요.)
  • 마켓플레이스: 부품을 모아 둔 가게. 여기에 등록하면 부품을 꺼내 쓸 수 있어요.
  • 에이전트(서브에이전트): AI 직원 한 명.
  • 입력창: Claude Code 화면 아래쪽, 글자를 쳐 넣는 칸.

📛 이름 안내: 제품 이름은 SoDam-Agent예요. 그런데 설치할 때 팀 뒤에 붙는 @sodamagent-marketplace는 가게의 내부 이름이라 글자가 달라요. 그대로 입력하면 됩니다(정상이에요).

📋 지금 버전으로 뭐가 되나요? (2026-07-11 기준): 팀 7종(웹앱·문서·리서치·마케팅·데이터·보안 감사·DevOps) + 직원 관리 도구 + Codex/Gemini CLI/Cursor 역할 번역(베타)까지 전부 설치 가능해요. 자세한 변경 이력은 README.md 맨 위 "현재 버전 상태" 안내를 확인하세요.

1. 준비 (딱 두 가지)

  1. Claude Code가 깔려 있어야 해요. (없으면 먼저 설치: 검색창에 "Claude Code" → 공식 사이트 claude.com/claude-code)
  2. 인터넷 연결.

(선택) web-app-team·research-team의 자료 검색 도구까지 쓰려면 Node.js가 필요해요. 없어도 AI 직원은 쓸 수 있고, 그 도구만 빠집니다. 필요하면 nodejs.org 에서 "LTS" 버튼을 눌러 설치하세요.

2. 설치하기 (그대로 따라 하기)

아래 글자는 검은 터미널이 아니라, Claude Code 화면 아래 "입력창" 에 칩니다.

1단계 · Claude Code 켜기

  • 평소에 Claude Code를 켜던 방법으로 켜세요. (입력창이 보이면 준비 완료.)

2단계 · 가게(마켓플레이스) 등록 — 맨 처음 딱 한 번

👉 입력창에 아래를 그대로 치고 Enter:

/plugin marketplace add sodam-ai/SoDam-Agent

🖥️ "마켓플레이스가 추가되었다"는 안내가 나오면 성공.

⚠️ 혹시 Marketplace file not found(못 찾음) 가 나오면: GitHub 반영에 1~2분 걸릴 수 있어요. 잠깐 뒤 다시 해 보세요.

3단계 · 팀 설치

👉 원하는 팀을 입력창에 치고 Enter (하나만 골라도 됩니다):

/plugin install web-app-team@sodamagent-marketplace
  • 문서 팀을 원하면: /plugin install docs-team@sodamagent-marketplace
  • 리서치 팀을 원하면: /plugin install research-team@sodamagent-marketplace
  • 마케팅 팀을 원하면: /plugin install marketing-team@sodamagent-marketplace
  • 데이터 팀을 원하면: /plugin install data-team@sodamagent-marketplace
  • 보안 감사팀을 원하면: /plugin install security-audit-team@sodamagent-marketplace
  • DevOps/배포팀을 원하면: /plugin install devops-team@sodamagent-marketplace

4단계 · (선택) 직원 관리 도구 설치

새 직원을 직접 만들고 가르치고 싶다면 이것도 설치하세요:

/plugin install sodam-agent@sodamagent-marketplace

5단계 · ⭐ 새로 설치한 걸 불러오기 — 가장 중요!

👉 먼저 이걸 입력창에 치고 Enter (완전히 껐다 켜지 않아도 바로 반영돼요, 실제 확인됨):

/reload-plugins

왜? 플러그인은 켤 때(또는 다시 불러올 때) 한 번 읽혀요. 그래서 그 전에는 방금 깐 직원·명령이 안 보입니다. (가장 흔한 막힘 지점이에요!)

이래도 안 보이면: 입력창에 /exit 치고 나간 뒤 다시 claude 로 켜세요(또는 창을 완전히 닫고 다시 열기).

3. 잘 됐는지 확인하기

👉 입력창에 치고 Enter:

/agents

🖥️ AI 직원 목록이 떠요. 거기서 web-app-team:reviewer 같은 이름을 찾으세요.

  • 이름 앞에 팀이름: 이 붙어 있어요 → 내가 깐 직원이 확실히 구분됩니다. (이게 핵심!)
  • 보이면 성공입니다. (다 봤으면 Esc 키로 빠져나오세요.)

4. AI 직원에게 일 시키기 (예시)

가장 쉬운 방법은 말로 시키는 것이에요. 입력창에 이렇게:

web-app-team:reviewer 한테 이 코드 좀 검토해 달라고 해줘

또는 글을 다루는 팀이면:

docs-team:editor 한테 이 글을 더 매끄럽게 다듬어 달라고 해줘

🖥️ Claude가 해당 직원(서브에이전트)을 불러서 일을 맡기고, 결과를 가져다 줍니다.

💡 입력창에 @ 를 치면 직원 목록이 떠서 골라서 부를 수도 있어요.

5. 새 직원 만들기 · 가르치기 (sodam-agent 도구)

4단계에서 sodam-agent까지 설치하고 재시작했다면, 입력창에 /sodam-agent: 까지 치면 아래 명령들이 떠요.

➕ 새 직원 만들기

/sodam-agent:new-agent

🖥️ 이름·하는 일·성격을 물어봐요. 답하면 내 직원이 만들어집니다. (예: "한국어로 친절히 설명하는 도우미")

🎓 직원 가르치기 (특훈)

/sodam-agent:training-agent

🖥️ 직원의 지시서를 고쳐 행동을 바꿔요. 예: 방금 만든 도우미를 더 짧게 대답하도록 가르쳐줘

"학습"이 뭐예요? AI를 다시 훈련시키는 게 아니라, 직원에게 주는 지시문을 바꾸는 거예요. (사람에게 "앞으로 이렇게 해줘" 하고 메모를 고쳐 주는 느낌.)

📋 팀 직원을 내 직원으로 복사

/sodam-agent:pick-agent

왜 복사가 필요해요? 팀 직원(web-app-team:reviewer 등)은 직접 못 고쳐요(업데이트 때 사라짐). 그래서 복사본을 만들어 그걸 가르칩니다. (도서관 책에 낙서 대신, 내 공책에 옮겨 적어 고치는 것과 같아요.)

💾 직원 저장 · 🗑️ 직원 삭제

/sodam-agent:save-agent     ← 만든 직원을 모든 프로젝트에서 쓰게 저장
/sodam-agent:remove-agent   ← 직원 삭제 (먼저 백업하고, "정말 지울까요?" 한 번 더 물어봐요)

⚠️ 삭제 주의: 목록에 내가 실제로 쓰는 직원이 같이 보일 수 있어요. 연습은 new-agent로 버려도 되는 직원을 만들어서 그걸 지워 보세요.

6. 더 이상 필요 없을 때 (제거)

👉 입력창에 치고 Enter:

/plugin

🖥️ 설치한 플러그인 목록이 나와요. 지우고 싶은 팀·도구를 골라 제거(uninstall) 를 누르면 끝.

제거는 Claude Code가 직접 안전하게 처리해서, 잘못 지워도 다시 설치하면 됩니다.

8. 안전 · 돈 관련 (꼭 알기)

  • 지워도 안전해요. 설치/제거는 Claude Code가 직접 관리합니다. 직원 삭제도 백업 + 확인을 거쳐요.
  • 비밀번호·키는 파일에 저장되지 않아요. (도구 설정·직원 만들기엔 키 "이름"만 들어갑니다.)
  • 이 도구는 보증 없이(있는 그대로) 제공돼요. 사용 책임은 본인에게 있어요.
  • 설치하는 외부 도구(예: 자료검색 context7)나 외부 서비스의 요금·약관은 본인이 직접 확인하세요. (대부분 무료 한도가 있지만, 정책은 바뀔 수 있어요.)

(선택) Codex에서도 쓰기 — 역할 번역 (베타)

Codex(다른 AI 코딩 도구)도 쓰신다면, 같은 팀을 Codex용으로도 만들 수 있어요.

솔직히 말하면: Codex는 "여러 직원이 따로 일하는 팀" 방식이 아니에요. 그래서 똑같은 팀이 아니라, 각 역할을 Codex가 알아듣는 지침서로 "번역" 해 드려요(베타).

⚠️ 이것만은 검은 터미널이 필요해요(플러그인 설치와 달라요). Codex를 쓰시는 분은 보통 터미널이 익숙할 거예요.

준비물: ① 이 프로젝트를 내려받은 폴더(아래 10번 참고) ② Node.js (nodejs.org 에서 LTS)

하는 법 — 내려받은 SoDam-Agent 폴더에서, 검은 터미널에 한 줄 (Codex로 쓸 폴더를 --dir 에):

node bin/cli.mjs install web-app-team --target codex --dir "C:\Codex로_쓸_내_프로젝트_폴더"

🖥️ 무엇이 만들어질지 먼저 보여주고 물어봐요 → "예" 하면 그 폴더에 AGENTS.md(역할 지침서)와 .agents/skills/... 가 생깁니다.

  • 다른 팀은 docs-team·research-team 으로 바꾸면 돼요.
  • 자료검색(context7) 도구가 필요하면, 화면에 나온 TOML 몇 줄을 ~/.codex/config.toml 에 붙여넣고 Codex를 재시작하세요.

쓰는 법: 그 폴더에서 Codex를 켜면 AGENTS.md를 읽고 역할대로 일해요.

잘 안 되면: 꼭 그 폴더에서 Codex를 켰는지 확인하세요(다른 폴더면 AGENTS.md를 못 읽어요). 그리고 Codex는 "지침"으로 따르는 거라, Claude Code처럼 여러 직원이 동시에 도는 건 아니에요(정상).

10. (고급) 마켓플레이스 대신 — 내 폴더로 써 보기

마켓 대신 내려받은 폴더를 직접 "가게"로 등록해도 됩니다. (검은 터미널 없이 클로드 안에서.)

  1. 이 프로젝트를 내려받아요(GitHub에서 ZIP 다운로드 → 압축 풀기).
  2. Claude Code 입력창에 (⚠️ 따옴표는 빼고, 공백·한글 없는 경로로): 
    /plugin marketplace add C:\내려받은폴더\SoDam-Agent
  3. 이어서 팀·도구 설치 — 이 줄을 빠뜨리면 직원이 안 보여요: 
    /plugin install web-app-team@sodamagent-marketplace
/plugin install sodam-agent@sodamagent-marketplace
  4. 껐다 켜면(재시작) 적용돼요. 그다음은 위 3·4·5단계 와 똑같아요.

💡 검은 터미널이 익숙하면 claude --plugin-dir "내려받은폴더\plugins\web-app-team" 도 됩니다.

11. FAQ (자주 묻는 질문)

질문 답
SoDam-Agent는 무료인가요? SoDam-Agent 자체는 무료(Apache-2.0)입니다. Claude Code 구독료와 연동 도구(예: context7) 요금은 각 서비스에서 확인하세요.
어떤 Claude 플랜이 필요한가요? Pro 이상 권장(자체 검증 전, 예상 기준). Free 플랜 동작은 미검증입니다.
오프라인에서 쓸 수 있나요? 설치에는 인터넷 필요. 이후 에이전트는 Claude API 연결이 있으면 동작. context7 자료검색은 온라인 필요.
직원이 MCP(context7 등)를 항상 직접 쓰나요? 대부분 그렇지만, 환경에 따라 직원이 직접 접근 못 할 수 있음(실사용 확인됨). 그럴 땐 정직하게 알리고 관리자가 대신 조회해서 전달 — 결과는 항상 정확하되, 누가 처리했는지 표시가 붙습니다.
어떻게 업데이트 하나요? /plugin 관리 화면에서 업데이트 확인, 또는 마켓 제거 후 재등록. 수정본은 pick-agent로 복사해 보관하세요.
내 데이터가 어딘가로 전송되나요? 아니요. SoDam-Agent 서버 없음. 모든 처리는 내 컴퓨터에서 이뤄집니다.
직접 팀을 만들 수 있나요? 네. sodam-agent 5개 명령으로 내 에이전트 만들기 가능. 팀 전체 만들기는 DEVELOPMENT.md 참고.
context7 없어도 되나요? 됩니다. 에이전트는 정상 동작하고, 실시간 라이브러리 문서 조회만 안 됩니다.
만든 에이전트를 공유할 수 있나요? 네. .md 파일 공유. 공유 전 개인정보·API 키 포함 여부 확인 필수.
