# AgentRoster

**한국어** | [English](./README.en.md)

> Claude Code에 **역할별 에이전트(AI 직원) 팀을 명령어 한 번으로 깔아주는** 비개발자용 도구입니다.
> 설정 파일을 손으로 만들 필요 없이 팀을 골라 설치하고, 마음에 안 들면 **되돌리기**로 원래대로 복구합니다.
>
> 이 도구는 팀을 **깔아주는 설치 도구**입니다. 에이전트를 대신 **실행해 주는 도구가 아닙니다.**

---

## 1. 준비물 (딱 하나)

- **Node.js 18 이상** — 컴퓨터에 없으면 https://nodejs.org 에서 **"LTS"** 버전을 받아 설치하세요.
  - 설치됐는지 확인: 검은 창(터미널)에 `node -v` 입력 → `v20.x` 처럼 숫자가 나오면 OK.
- (선택) **Claude Code** — 깐 에이전트는 Claude Code 안에서 사용합니다.

> AgentRoster 자체는 추가로 설치할 게 없습니다(외부 부품 0개). `node`만 있으면 바로 돕니다.

---

## 2. 빠른 시작 (3단계, 약 5분)

1. 이 폴더에서 터미널을 엽니다. *(Windows: 폴더 주소창에 `cmd` 입력 → 엔터)*
2. 아래를 입력하고 엔터:
   ```
   node bin/cli.mjs
   ```
3. 화면 메뉴에서 **번호만 입력** → "팀 설치하기" → 팀 선택 → 확인 → 끝!

> Windows는 `bin\시작하기.bat`를 **더블클릭**해도 됩니다.

설치가 끝나면 안내가 뜹니다 — **Claude Code를 완전히 껐다 켠 뒤** `reviewer 에이전트로 이 코드 검토해줘` 처럼 써보세요.

---

## 3. 명령어 (메뉴 대신 바로 쓰기)

| 명령 | 하는 일 |
|------|---------|
| `node bin/cli.mjs` | 대화형 메뉴 (가장 쉬움) |
| `node bin/cli.mjs list` | 설치할 수 있는 팀 목록 |
| `node bin/cli.mjs doctor` | 내 컴퓨터 환경 점검 |
| `node bin/cli.mjs install web-app-team` | 웹앱팀 설치 |
| `node bin/cli.mjs custom` | 역할을 골라 나만의 팀 만들기(마법사) |
| `node bin/cli.mjs roles` | 내 역할 만들기/고치기/지우기 |
| `node bin/cli.mjs verify` | 설치 상태 + Claude Code에서 확인하는 법 보기 |
| `node bin/cli.mjs rollback` | 되돌리기 |
| `node bin/cli.mjs export web-app-team` | 팀을 파일로 내보내기(공유용) |
| `node bin/cli.mjs import <파일>` | 받은 팀 파일을 안전하게 설치 |

옵션: `--dir <폴더>` 설치할 폴더 지정(기본=현재 폴더) · `--out <파일>` 내보낼 파일 경로 · `--yes` 확인 질문 없이 진행

> **팀 공유:** `export`로 만든 `*.agentroster.json` 파일을 다른 사람에게 주면, 그 사람도 `import`로 같은 팀을 깝니다. 공유 파일엔 **비밀번호·API 키 값이 들어가지 않습니다**(키 이름만). 받은 파일을 `import`할 땐 **설치될 명령을 미리 보여주고 확인**받으며, 위험한 이름·형식·대용량 파일은 자동 차단합니다.

---

## 4. 설치할 수 있는 팀 (3종)

| 팀 id | 이름 | 역할(AI 직원) |
|-------|------|------|
| `web-app-team` | 웹앱 빌드팀 | planner · frontend-dev · backend-dev · reviewer |
| `docs-team` | 문서/콘텐츠팀 | writer · editor · fact-checker |
| `research-team` | 리서치팀 | researcher · analyst · critic |

> **내 역할 직접 만들기:** `roles` 명령(또는 메뉴 "내 역할 관리")으로 나만의 역할(예: "SEO 전문가")을 만들 수 있어요. 쉬운 질문(이름·하는 일·권한)에 답하면 끝. 만든 역할은 **"나만의 팀 만들기"에서 기본 역할과 함께** 고를 수 있고, **홈 폴더에 저장돼 어느 프로젝트에서나 재사용**됩니다.

---

## 5. 파일은 어디에 생기나요?

설치하면 **현재(또는 `--dir`로 지정한) 폴더** 안에 만들어집니다:

| 위치 | 내용 |
|------|------|
| `.claude/agents/*.md` | 에이전트(직원) 파일들 |
| `.mcp.json` | 도구(MCP) 연결 설정 — 기존 설정은 **덮어쓰지 않고 합쳐집니다** |
| `.agentroster/backups/...` | 되돌리기용 백업 (자동으로 Git 제외 처리) |

---

## 6. ⚠️ 설치 후 가장 중요한 한 가지

**새로 깐 에이전트는 "완전히 새로 켠" Claude Code 창에서만 보입니다.**
- Claude Code를 **완전히 종료**하고 **다시 켜세요.** (이전 대화가 안 보이는 **텅 빈 새 창**이어야 함)
- "닫았다 다시 열기"인데 이전 대화가 그대로 보이면 → 아직 **이어하기 모드**라 새 직원이 안 보입니다. 완전히 새 창으로 켜세요.

**확인 방법:** 새 창에서 `/agents` 또는 `reviewer 에이전트 불러줘` 입력 → 깐 역할 이름이 보이면 성공.
설치 상태가 헷갈리면 `node bin/cli.mjs verify` 로 깔린 에이전트와 확인법을 다시 볼 수 있어요.

## 7. 문제가 생겼을 때 (증상 → 원인 → 해결)

| 증상 | 원인 | 해결 |
|------|------|------|
| `node`/`npx` 명령이 없다고 나옴 | Node.js 미설치 | https://nodejs.org 에서 LTS 설치 후 다시 시도 |
| 설치 중 멈추거나 네트워크 오류 | 회사 프록시·방화벽 차단 | 다른 네트워크에서 시도 / 관리자에게 차단 해제 요청 |
| Windows가 "이 앱을 차단"이라고 함 | SmartScreen·백신 | 파일 우클릭 → 속성 → "차단 해제" 체크 / 백신 예외 추가 |
| PowerShell이 스크립트 실행을 막음 | 실행 정책 제한 | 정책을 임의로 영구 변경하지 말고, `node bin/cli.mjs`(=cmd)로 실행하면 우회됨 |
| 한글이 깨져 보임 | 경로에 한글·공백 / cmd 인코딩(CP949) | 영문·공백 없는 경로 권장. `.bat`는 시작 시 UTF-8로 맞춰져 있음 |
| 깐 에이전트가 Claude Code에 안 보임 | **재시작을 안 했거나 이어하기 모드** | Claude Code **완전 종료 후 텅 빈 새 창**으로 다시 켜기 (가장 흔한 원인) |
| 에이전트가 엉뚱한 곳에 깔린 느낌 | 전역 vs 프로젝트 폴더 혼동 | 이 도구는 **현재 폴더(프로젝트)**에 깝니다. `doctor`로 대상 폴더 확인 |
| "같은 이름 에이전트가 있다" | 동명 에이전트 충돌 | 설치 전 자동 백업됨 → 덮어써도 `rollback`으로 복구 가능 |
| 에이전트가 도구 오류를 냄 | MCP가 요구하는 API 키 없음 | 해당 MCP 제공처에서 키 발급 → **OS 환경변수**에 키 이름으로 저장(파일에 직접 넣지 마세요) |
| Claude Code가 에이전트를 모름 | Claude Code 미설치/구버전 | Claude Code 설치/업데이트 후 다시 시도 |
| 되돌리고 싶은데 방법을 모름 | — | `node bin/cli.mjs rollback` → 시점 선택 |
| 백업이 어디 있는지 모름 | — | `현재폴더\.agentroster\backups\` 안에 시점별로 보관 |
| 권한(쓰기) 오류 | 폴더 쓰기 권한 부족 | 관리자 권한은 **필요 없습니다.** 내 문서 등 쓰기 가능한 폴더에서 실행 |

> macOS/Linux: 경로·진입 방식이 조금 다릅니다. 현재는 **Windows를 우선 지원**하며, 핵심 명령(`node bin/cli.mjs ...`)은 동일하게 동작합니다.

## 8. 안전 · 면책 (꼭 읽어주세요)

- 모든 설치는 **먼저 자동 백업**한 뒤 진행됩니다. 언제든 `rollback`으로 되돌릴 수 있습니다.
- **비밀번호·API 키 같은 비밀은 파일에 저장하지 않습니다.** (MCP 설정엔 키 "이름"만 들어가고, 값은 사용자 OS 환경변수에 둡니다.)
- 이 도구는 **있는 그대로(AS IS)** 제공되며 **보증하지 않습니다.** 사용 책임은 사용자에게 있습니다.
- 설치하는 외부 도구(MCP)·API의 **요금·약관·정책은 사용자가 직접 확인**하세요.
